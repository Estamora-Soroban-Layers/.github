## Repositories

| Repository | Role | Technology |
| :--- | :--- | :--- |
| [**`estamora-contracts`**](https://github.com/Estamora-Soroban-Layers/estamora-contracts) | Soroban smart contracts: milestone escrow, dispute arbitration, and spend caps | Rust, Soroban SDK v27.0.6 |
| [**`estamora-sdk`**](https://github.com/Estamora-Soroban-Layers/estamora-sdk) | Client SDK, pre-flight simulation engine, transaction builders, and error decoders | TypeScript, `@stellar/stellar-sdk` |
| [**`estamora-app`**](https://github.com/Estamora-Soroban-Layers/estamora-app) | Merchant dashboard, interactive checkout demo, and Freighter operator console | React 19, Vite, Tailwind |
| [**`estamora-docs`**](https://github.com/Estamora-Soroban-Layers/estamora-docs) | Documentation hub, technical guides, contract references, and architecture maps | Markdown & Docs |
| [**`.github`**](https://github.com/Estamora-Soroban-Layers/.github) | Community health files and organization landing profile (this repository) | GitHub Community Standards |
