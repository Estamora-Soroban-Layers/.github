# Security Policy

## Reporting Security Vulnerabilities

Security is vital for decentralized payment protocols handling funds and delegated agent limits.

If you identify a security vulnerability:
1. **Do not create public issues.**
2. Report the vulnerability privately via GitHub Security Advisories or contact maintainers directly.
3. Include detailed reproduction steps and impact assessments.

## Response Process

- We acknowledge reports within 48 hours.
- Critical vulnerabilities in on-chain contracts are addressed with priority patches and community advisories.
